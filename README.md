One job title, 60 characters at most, the weirdest I could think of. A blind
judge compares titles two at a time and picks the weirder, funnier one.

## The title

> Senior Apologizer to Angry Geese

A real-sounding senior role with one absurd, specific twist: apologizing is
a plausible corporate function, angry geese are not a plausible client base.
Thirty-two characters, readable at a glance.

## Run

```sh
node main.ts
```

Writes the title to `/output/entry.txt` (or `$OUTPUT_PATH` when set).
Node 22 or later, standard library only, deterministic, no network access.
